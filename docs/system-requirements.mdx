# Системные требования

## Системные требования игры {#minecraft}
:::info[Источники]
Системные требования игры были взяты из официальных источников:
- [Minecraft.net](https://www.minecraft.net/en-us/article/minecraft-java-edition-system-requirements)
- [Minecraft Wiki](https://minecraft.wiki/w/Java_Edition)
- Архивные редакции help.mojang.com
- Новости с feedback.minecraft.net

Системные требования были скорректированы согласно требованиям версий **Java**, поставляемых в лаунчере
:::

:::tip[Как читать эти таблицы]
- **ОЗУ для игры** - объем ОЗУ для выделения в лаунчере. Должен быть меньше доступной в системе ОЗУ.
- **ОЗУ с модами** - объем ОЗУ для выделения в лаунчере, при игре с популярными сборками

Эти требования являются **ориентиром** - игра **может** заработать на системах, не соответствующих минимальным требованиям. Главное - чтобы были соблюдены требования по версии OpenGL/Vulkan и требуемая игре версия Java поддерживалась вашей ОС
:::

## Системные требования лаунчера {#launcher}
* **Jar-версия лаунчера**: Любая ОС, установленная Java 8 или новее (рекомендована Java 11 или новее)
  * Дополнительно для **Linux**: Соответствующая среде рабочего стола версия `xdg-desktop-portal`
* **Установщик для Windows**: Windows 7 SP1 (x64) или новее
* **Версия для Flathub**: Любой дистрибутив Linux с поддержкой Flatpak, соответствующая среде рабочего стола версия `xdg-desktop-portal`

:::info[Обратите внимание!]
Legacy Launcher не имеет поддержки Bedrock-издания Minecraft и иных игр, нежели Minecraft: Java Edition
:::
:::info[Обратите внимание!]
Legacy Launcher не имеет версии для мобильных устройств
:::
