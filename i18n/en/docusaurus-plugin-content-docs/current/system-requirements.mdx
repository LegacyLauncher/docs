# System Requirements

## Minecraft System Requirements {#minecraft}
:::info[Sources]
The game's system requirements were taken from official sources:
- [Minecraft.net](https://www.minecraft.net/en-us/article/minecraft-java-edition-system-requirements)
- [Minecraft Wiki](https://minecraft.wiki/w/Java_Edition)
- Archived revisions of help.mojang.com
- News posts on feedback.minecraft.net

The system requirements have been adjusted according to the requirements of the **Java** versions provided by the launcher
:::

:::tip[How to read these tables]
- **Game RAM** - the amount of RAM to allocate in the launcher. It must be less than the RAM available in the system.
- **Game RAM with mods** - the amount of RAM to allocate in the launcher when playing popular modpacks

These requirements are a **guideline** - the game **may** run on systems that do not meet the minimum requirements. What matters most is that the OpenGL/Vulkan version requirement is met and that the Java version required by the game is supported by your OS
:::

## Launcher System Requirements {#launcher}
* **Jar version of the launcher**: Any OS with Java 8 or newer installed (Java 11 or newer is recommended)
  * **Linux-specific**: `xdg-desktop-portal` implementation matching your desktop environment
* **Installer for Windows**: Windows 7 SP1 (x64) or newer
* **Version for Flathub**: Any Linux distribution with Flatpak support, `xdg-desktop-portal` implementation matching your desktop environment

:::info[Please note!]
Legacy Launcher does not support the Bedrock edition of Minecraft or games other than Minecraft: Java Edition
:::

:::info[Please note!]
Legacy Launcher does not have a version for mobile devices
:::
